# rogaircon.co.za

Website for Rog Air-Conditioning & Refrigeration (Chatsworth, Durban). Static site
generated by a dependency-free Python script.

## Edit & build

- Business details (phone, WhatsApp, email, address) live in `CONFIG` in `build.py`.
- Page copy lives in the page functions in `build.py`.
- Run `python build.py` to regenerate the `.html` pages, `sitemap.xml` and `robots.txt`.
- Bump `asset_version` in `CONFIG` whenever `assets/css` or `assets/js` change.
- Raw client photos stay in `_originals/` (gitignored); web versions are in `assets/img/`.

## Deploy (cPanel Git Version Control, zacp103.webway.host, user rogairconco)

1. Push to GitHub (`main`).
2. cPanel → Git Version Control → Manage → Pull or Deploy → **Update from Remote** → **Deploy HEAD Commit**.

`.cpanel.yml` copies the site into `~/public_html/` (rogaircon.co.za is the primary domain).
